# Divider

A 1 pt separator line.

Mirrors `Divider` in MetalGraphics.

## Props

| Prop | Type | |
|---|---|---|
| `vertical` | boolean | Vertical instead of horizontal. |

Every component also takes `className` and `style`. Most take `state` (`"hover" | "pressed" | "focused" | "disabled"`) to draw a state without a pointer on it.

## Example

```jsx
<Divider />
```
